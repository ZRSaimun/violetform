The main index now uses the actual recorded visual sequence, rather than the earlier independently illustrated design. The earlier index is preserved as independent-study.html.

## What this is

A scroll-controlled **visual reconstruction** of the visible recording. It is not recovery of the original application, its 3D models, payment logic or source. Buttons painted inside source frames are not native controls. The viewer has real range/chapter/restart/pause controls and reduced-motion support.

## Fidelity limits

The source records a screen. Cropping, perspective, motion blur and clipped page edges remain. This reproduces recorded visuals rather than recovering the original application.

Source frame content is recorded at a few hundred pixels across. Resampling the canvas does not create native HD detail. Atlas tile dimensions: 480×270; frame count: 48.

Only cropped website content is included. Browser/social account UI and presenter footage were excluded. Original imagery and brand marks remain attributable to their respective creators; no ownership or asset-reuse licence is asserted by this repository. The independent source code is retained; purchased Office source/models were not used.
